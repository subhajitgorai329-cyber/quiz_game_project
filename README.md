# Screenshots

Place your application screenshots in this folder. Suggested filenames:

1. `01_welcome_screen.png` - Program start and welcome message
2. `02_question_display.png` - A question with its four options shown
3. `03_invalid_input.png` - Invalid input being rejected and re-prompted
4. `04_correct_answer.png` - "Correct!" feedback message
5. `05_incorrect_answer.png` - "Incorrect!" feedback showing the right answer
6. `06_result_pass.png` - Final result screen showing PASS
7. `07_result_fail.png` - Final result screen showing FAIL
8. `08_play_again_prompt.png` - The "Play again? (Y/N)" prompt

See the main README.md and Project_Report.docx for full details on what
each screenshot should demonstrate.
